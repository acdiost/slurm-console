# 分区查询

`/partitions` 展示连接身份当前可见的 Slurm 分区，支持名称搜索、状态筛选、名称/配置节点数/配置 CPU 数/最长时限排序和服务端分页。URL 保存集群、筛选、排序、列表页、分区详情及关联节点页。默认每 10 秒刷新，可暂停；刷新失败会隐藏旧查询结果并显示错误。

详情展示节点表达式、时限、节点数与 CPU 约束、默认及最大内存、共享配置、优先级、账户/组/QOS、替代分区、节点集、拓扑及 TRES。查询只返回选定 DTO，不代理任意 REST 路径，也不提供分区编辑。

## 权限与资源口径

列表和详情要求目标集群 `partitions.read`。详情中的关联节点资源额外要求 `nodes.read`，缺权时不请求节点，仅展示分区配置容量；作业链接按 `jobs.read` 显示，各目标接口独立授权。每次请求检查活动用户及当前授权，缓存不绕过权限。

关联节点通过节点返回的 `partitions` 列表精确匹配，不展开节点表达式、不按名称前缀匹配。资源汇总复用总览口径：不可用节点的未分配资源不计为空闲，未知 GPU 不填零。配置节点数与可见关联节点数不同时标注覆盖不完整；配置节点非零但没有可见节点时，资源显示无法统计。上游节点读取失败为独立错误，不影响分区约束展示。节点分页独立请求，因此与汇总可能有采样时间差。

多个分区可以共享节点，列表中的配置节点数/CPU 数不能跨分区相加。分区配置与节点资源分别显示来源时间和缓存状态；读取期间配置修改或连接停用时返回 409，避免混合连接版本。

## Slurm 字段语义

| 分区状态 | 含义 |
|---|---|
| UP | 接受新作业并允许调度；实际运行仍受节点状态和约束影响 |
| DOWN | 接受新作业，暂停排队作业调度；已运行作业继续 |
| DRAIN | 拒绝新作业提交，已排队作业仍可能调度 |
| INACTIVE | 拒绝新作业提交，并暂停排队作业调度 |

分区 DRAIN 与节点 DRAIN 分别说明。数值保留显式零、未设置和无限三种状态。仅内存限制的显式零按 Slurm 语义显示不限；其他约束的零不会统一转换为无限。默认时限未设置时，Slurm 使用最长时限。读取 `partition_memory_per_cpu/node` 规范字段，不直接解释带标志位的原始 `memory_per_cpu`。

空 ACL 显示“未显式指定”，由 Slurm 的默认规则决定准入，不推断平台已授予提交资格。当前 v0.0.43 分区响应未提供可靠的默认分区标记，页面不推断该标记。

## API

前缀 `/api/v1/clusters/{clusterId}`，成功响应统一 `{data,requestId}`，拒绝未知和重复参数。

| 路径 | 参数/响应 |
|---|---|
| `GET /partitions` | page/perPage/q/state/sort/order；items、分页及来源时间 |
| `GET /partitions/{partitionName}` | 无查询参数；item、revision、来源时间、resources |

名称按列表精确匹配，不存在或不可见返回 404。resources 的 status 为 ok/forbidden/error；失败及缺权时 item=null。ok 的 item 包含 summary、configuredNodes、complete。最长时限排序中无限大于有限值，未知始终排在末尾。同值按名称稳定排序。

语义依据 [SchedMD scontrol](https://slurm.schedmd.com/scontrol.html)，字段以部署环境的 v0.0.43 OpenAPI 为准。应用不修改 Slurm 分区、角色或外部服务配置。

自动化测试覆盖独立节点授权、缓存后撤权、精确节点归属、部分来源失败、覆盖缺失、混合配置版本拒绝、有限/无限/未知排序及前端分页、筛选、错误隐藏和约束显示。
