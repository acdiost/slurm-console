# 筛选条件持久化

各主要列表提供具名筛选方案，保存在平台 `saved_filters` 数据集合中，同一用户可跨浏览器使用。按本人、模块和集群隔离；多集群首页与操作审计使用平台范围，不绑定某个业务页集群。

## 使用

先在页面应用筛选、排序或每页数量，再展开“保存与管理方案”，输入名称并“另存方案”。可设置一个默认方案，或选择已有方案后应用、更新、取消默认及删除。每个范围最多 10 个，每个用户总计 100 个；名称去除首尾空白后为 1–40 字，同一范围不区分大小写唯一。

只在地址没有明确列表条件、分页、详情或操作上下文时恢复默认方案。显式 URL 优先，便于分享链接与恢复操作结果；集群选择参数不妨碍恢复。首次恢复前暂不加载业务列表，避免先显示不符合默认方案的数据。未配置默认或方案读取失败时沿用页面条件；读取失败可手动刷新，不自动写入或重试。

“应用方案”和“重置当前条件”都会清除分页、详情、临时编辑、选择和操作确认状态。重置回到页面默认条件，本次访问不再次套用已保存默认，也不删除服务器上的方案。只保存已应用到地址的条件，尚未提交的输入框内容不保存。

## 可保存范围

| 模块 | 条件范围 |
| --- | --- |
| 作业 | 搜索、用户、账户、分区、QOS、状态、排序、每页数量 |
| 节点 | 搜索、分区、状态、矩阵/表格视图、排序、每页数量 |
| 分区 | 搜索、状态、排序、每页数量；不保存分区详情选择 |
| Linux 用户 | 搜索、来源、账户类别、排序、每页数量 |
| Account / Slurm 用户 / Association | 当前标签页及适用的搜索、账户、用户、分区、类别、排序 |
| QOS / Fairshare | 当前标签页及适用的搜索、账户、用户、类别、排序 |
| TRES | Association/QOS 目标类别、搜索、账户、用户、排序 |
| Reservation | 搜索、状态、排序 |
| GPU | 搜索、指标状态、节点排序；不保存 GPU 详情与趋势参数 |
| 历史作业 | 搜索、用户、账户、分区、QOS、Job ID 查询、状态、提交时间窗口、排序 |
| 多集群首页 | 搜索、配置状态、排序、每页数量 |
| 操作审计 | 搜索、集群、发起人、动作、状态、起止时间、排序、每页数量 |

前后端共享 [字段目录](../backend/internal/savedfilters/catalog.json)，后端独立校验。历史和审计时间保存为固定起止时间；历史页面默认的最近 24 小时在显示时写入地址，保存后不会随时间滚动。历史窗口仍不超过 31 天。空条件方案合法，历史页面应用时补充最近 24 小时。

不保存页码、详情记录、资源编辑项、单项/批量操作编号、proof、确认短语、原因、凭据或任意 URL；旧数据出现未知字段时返回 `compatible=false,usable=false` 和空条件，不恢复隐藏数据，仍允许本人删除或使用合法条件覆盖。

## 权限与接口

只需相应模块与集群读取权限，无须调度写权限。选定子列表还要求对应读取权限，例如 QOS 与 Association 的区分；撤权后不再读取、保存或应用相应方案。删除只影响本人的偏好，因此撤权后仍允许本人通过 API 删除。平台 Super Admin 也不能读取或修改其他用户的方案。原生 Collection 的列表、查看、创建、更新和删除规则全部锁定，自定义接口不接受 owner。

| 接口 | 输入 |
| --- | --- |
| `GET /api/v1/saved-filters?module=jobs&clusterId=…` | 读取本人当前范围，返回 items、maxPerScope=10、maxPerUser=100 |
| `POST /api/v1/saved-filters` | `{module,clusterId,name,conditions,isDefault}`；平台范围 clusterId 为空 |
| `PATCH /api/v1/saved-filters/{filterId}` | `{name,conditions,isDefault,revision}`；完整更新，范围不可变 |
| `DELETE /api/v1/saved-filters/{filterId}` | `{revision}` |

版本从 1 开始递增；更新和删除要求匹配当前版本。更换默认方案会在同一事务中取消旧默认并递增其版本；数据库索引保证同一范围默认唯一。过期版本、重名或数量上限返回 409，界面要求刷新后重试，不静默覆盖。其他用户的 ID 返回 404；未知字段或非法时间返回 400。完整协议见 [OpenAPI 0.22.0](../api/openapi.yaml)。

方案只改变只读列表条件，不授予权限，不调用 Slurm 控制，不创建操作确认或审计意图。保存在应用数据库中，随既有加密备份一起备份；不增加外部组件或部署配置。
