# 运维操作模板

`/operation-templates` 提供按本人、集群保存的具名操作模板，支持取消作业、节点 Drain 和 Resume。模板保存名称、说明、可选默认原因和核查清单；每次使用都重新填写目标，经人工核查后进入已有批量确认流程。列表、保存、选择与准备均不发送 Slurm 控制请求。

## 使用流程

1. 选择集群，创建一个动作模板。名称为 1–40 字，说明最多 500 字，默认原因为空或 2–220 字单行内容；清单可为空，最多 8 条，每条 1–160 字。
2. 使用模板，输入本次 1–10 个不重复的明确 Job ID 或节点名，不接受 ALL、范围和选择表达式。目标、凭据、URL、确认信息和可执行脚本不能保存在模板中。
3. 完成本次清单核查，准备操作。修改目标会清除已勾选项，关闭确认后清除本次目标和勾选项。清单用于临时人工引导，不持久记录，也不作为服务端安全判断或合规凭证。
4. 服务端逐项读取实际资源并验证当前身份、权限与连接；全部允许后，在既有确认框重新输入 `CANCEL N`、`DRAIN N` 或 `RESUME N`，核对原因后执行。默认原因可修改，不自动代填确认短语。
5. 结果沿用逐项持久操作编号和只读恢复；页面刷新不会重新发送控制。

Drain / Resume 保持既有节点控制语义与限制，仍需核对节点状态和实际作业。模板不意味着节点已排空，Resume 可能重新允许调度；本功能不编排维护步骤或等待作业结束。作业身份关联、root 作业保护及单项目标限制沿用[批量操作](bulk-operations.md)。

## 范围、版本与授权

每人每集群最多 20 个模板，每人合计最多 100 个；同一范围名称忽略首尾空白和大小写后唯一。模板限本人访问，即使平台 Super Admin 也不能查看他人模板。原生 `operation_templates` Collection API 锁定，随数据库加密备份。

元数据和准备接口要求对应动作的读取及控制权限：`jobs.read + jobs.cancel`、`nodes.read + nodes.drain` 或 `nodes.read + nodes.resume`。列表只显示本人当前获准的动作，编辑同时检查原动作与新动作权限。停用集群可管理本人元数据，实际准备和执行仍要求启用且配置有效的集群。撤权后接口拒绝访问，页面隐藏旧内容。

修改、删除和准备必须带最新 `revision`。过期版本、重名或超出配额返回 409；其他用户的模板返回 404。保存和删除在同一事务中复查授权、完成元数据变更及平台审计，审计失败则回滚。

准备读取资源后再次复查当前模板版本和权限；期间模板修改或删除会使准备失败。成功准备形成固定快照，之后编辑或删除模板不改写或取消该批次。用户最终确认的是框内展示的模板版本、动作与完整目标；实际发送前仍按原控制服务逐项复查资源状态、权限、身份和连接修订。准备最多有效两分钟，不产生持久执行队列。

## API 与审计

前缀 `/api/v1/clusters/{clusterId}/operation-templates`，契约见 OpenAPI 0.27.0。

| 方法与路径 | 输入与响应 |
| --- | --- |
| `GET /` | 本人当前可访问模板和配额，无查询参数 |
| `POST /` | `{name,action,description,defaultReason,checklist}`，返回 revision=1 的模板 |
| `PATCH /{templateId}` | 完整元数据及当前 revision，返回 revision+1 |
| `DELETE /{templateId}` | `{revision}`，返回 `{deleted:true}` |
| `POST /{templateId}/prepare` | `{revision,targets}`，返回 `{template,prepared}` |

请求拒绝未知字段及未知/重复查询参数。执行继续调用已有 `bulk-control/{batchId}/execute`，没有新增执行入口、自动运行、重试、调度或任意脚本能力。

模板增改删审计记录 `operation_templates.create/update/delete`、模板 ID、名称及版本，保存时记录动作。真正控制仍使用原有逐项目标审计，保存执行原因、请求编号和核实结果；这些控制审计未附加模板来源，不应据此声称具有独立模板运行历史。清单与默认原因不复制到元数据变更审计。

## 验证

2026-10-31 在隔离虚拟机实例完成界面验证：三类模板可保存，空清单可用；简单保持作业 18 经模板核查、默认原因、手工确认和既有批量执行后核实为 CANCELLED，逐项审计保留。没有执行节点 Drain / Resume，原 DOWN 节点不变。Slurm 正常保留测试作业记账记录。
